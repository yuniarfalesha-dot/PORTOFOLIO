# Plantify

Website e-commerce makanan sehat berbasis HTML5 + CSS3.

## Halaman
- index.html
- menu.html
- product-detail.html
- cart.html
- about.html
- contact.html

## Teknologi
- HTML5 semantic
- CSS3
- CSS Grid + Flexbox
- CSS variables
- Responsive media queries
- Tanpa JavaScript
- Tanpa framework

## Catatan
Gambar produk menggunakan URL gambar online agar project langsung memiliki visual saat dibuka. URL tersebut bisa diganti dengan file lokal di folder `images/` ketika aset final sudah tersedia.

Semua tombol/filter/cart saat ini masih berupa tampilan statis dan sudah diberi struktur/class agar mudah ditambahkan JavaScript pada tahap berikutnya.
